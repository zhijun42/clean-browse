# 清净浏览 — Bilibili & 知乎

一个适用于 Chrome / Opera 的轻量 Manifest V3 扩展，清理搜索推荐和阅读干扰。

## 功能

- Bilibili：清空顶部搜索框的推荐词，隐藏首页直播卡片。
- 知乎（含专栏）：清空顶部搜索框的推荐词，隐藏「大家都在搜」、空搜索框下拉中的「搜索发现」、侧栏横幅广告和文章内图片广告。
- 保留自己输入的搜索词、输入后的搜索建议、搜索历史、文章正文、作者信息和普通视频卡片。
- 页面动态加载或重新写入推荐词后，自动继续清理。

广告通过页面容器识别，与 MathWorks、阿里云等具体品牌无关。该扩展负责隐藏匹配的页面元素，广告请求本身仍可能发生；网站改版后可能需要更新规则。

## 安装或更新

1. 在 Chrome 打开 `chrome://extensions/`，在 Opera 打开 `opera://extensions/`。
2. 开启开发者模式，选择「加载已解压的扩展程序」，选中 `clean-browse` 目录。
3. 已安装旧版时，直接在旧扩展卡片上点击「重新加载」，名称会变为「清净浏览 — Bilibili & 知乎」。
4. 刷新已经打开的 Bilibili / 知乎页面，让更新后的内容脚本生效。

项目目录为 `clean-browse`。扩展只在 Bilibili 和知乎域名下运行，不申请其他 API 权限，不上传任何数据。

## 验证

使用 Node.js 22 或更新版本，先运行 `npm install`，再运行 `npm test`。测试会在隔离的 Chromium 中加载真实扩展，用本地构造的两站页面检查推荐清理、动态更新、误隐藏和搜索提交；不会访问你的浏览器会话。

首次测试前可运行 `npx playwright install chromium` 安装测试浏览器。
